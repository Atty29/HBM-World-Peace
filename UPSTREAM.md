# Upstream provenance

HBM: World Peace is a modified fork derived from:

- **Project:** HBM's Nuclear Tech Modernized
- **Repository:** https://github.com/Raptor324/HBM-Modernized
- **Imported upstream commit:** `0365cef5956016913095eeeb9366f26c601ca9a0`
- **Import date:** 2026-10-03
- **License:** GNU General Public License v3.0

The upstream `gradle.properties` at the imported revision credits the project authors as **RaptorDev, TRFFuchs, razchexlitiel, HyperiO**, with additional contributors listed there. The upstream README also acknowledges **The Bobcat** as author of the original HBM's Nuclear Tech Mod.

This repository is intentionally modified and should not be represented as an official upstream build. World Peace-specific problems should be reported here rather than to the upstream project unless the problem is independently reproduced in upstream HBM Modernized.

The original upstream English and Russian READMEs are preserved as `UPSTREAM-README.md` and `UPSTREAM-README.ru.md`. The upstream support page is preserved as `UPSTREAM-SUPPORT.md` so its original support information is not confused with support for this fork.

Phase 0 imports the audited upstream source without gameplay alterations. Subsequent World Peace commits are expected to diverge from upstream according to `DANGER-AUDIT.md`.
