# HBM: World Peace

> **Keep the engineering. Remove the apocalypse.**

HBM: World Peace is a safety-focused fork of **HBM's Nuclear Tech Modernized** for Minecraft 1.20.1.

The goal is to preserve the industrial side of HBM — machines, metallurgy, chemistry, power systems, reactors, automation, tools and protective equipment — while removing strategic weapons, catastrophic map destruction, persistent radiation contamination and similar world-ending mechanics.

## Current status

**Phase 0 — upstream baseline import.**

The gameplay source in this baseline is intentionally still the audited upstream implementation. No World Peace safety changes are claimed until later commits apply the rules in [`DANGER-AUDIT.md`](DANGER-AUDIT.md).
